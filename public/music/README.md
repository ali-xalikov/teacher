## O‘z musiqangizni qo‘yish

1. MP3 faylni shu papkaga `teachers-day.mp3` nomi bilan saqlang
   (yoki boshqa nom ishlatmoqchi bo‘lsangiz — `src/pages/TeacherPage.tsx` ichida
   `<MusicToggle />` komponentiga `src` prop‘ini bering).
2. Fayl tavsiya: MP3, 1–2 MB gacha, 20–60 soniya, musiqa uzluksiz (loop).

Yo‘q bo‘lsa, sayt buzilmaydi — 🎵 tugmasi bosilganda
